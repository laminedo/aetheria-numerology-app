# AETHERIA • Athletic Workout & Tabata Interval Web App

A high-performance, athletic-grade Workout Timer & Tabata Interval Web Application designed with a high-contrast dark theme, voice coaching, custom routines, and presets from **Beginner to Advanced**.

---

## ⚡ Features

- **Intervals Setup & Customization**:
  - 🟡 **Prepare** (:15) - Countdown before start
  - 🟢 **Work** (:20) - High intensity exercise duration
  - 🔴 **Rest** (:09) - Recovery interval
  - 🔵 **Rounds** (8) - Work + Rest sets per cycle
  - 🟡 **Cycles** (3) - Number of round sets
  - 🟡 **Rest Between Cycles** (:30) - Extended recovery period
  - 🔵 **Cooldown** (:00) - Post-workout recovery
- **Interactive Value Picker**: Instant slider & quick stepper modal (+1s, -1s, +5s, +10s, preset chips)
- **Massive Split-Screen Runner Display**:
  - Real-time phase color switching: Lime Green (**WORK**), Crimson Red (**REST**), Amber (**PREPARE**), Sky Blue (**COOLDOWN**)
  - Large condensed athletic countdown timer
  - Subpanel previewing the next interval
  - Live "Rounds Left" indicator
  - Skip forward, skip backward, pause, resume, and restart controls
- **Sound Engine & Voice Coaching**:
  - Web Audio synthetic chimes (3-2-1 countdown beeps, work start whistles, rest tones, victory fanfare)
  - SpeechSynthesis voice coach announcements ("Work!", "Rest", "Prepare")
  - Screen WakeLock integration to keep mobile and desktop screens awake during training
- **Preset Library (Beginner to Advanced)**:
  - **Beginner**: Gentle Starter Tabata (10s/20s), Beginner Cardio Boost (15s/15s), Core & Stability
  - **Intermediate**: Classic Tabata 20/10, Fat Burn HIIT 30/15, Boxing Fitness Rounds
  - **Advanced**: Spartan 40/20 Beast, Tabata Inferno 30/10, Pro MMA Championship (3m rounds)
- **Boxing & Circuit Rounds Mode**: Dedicated combat sports timer with 10s warning clapper
- **Precision Stopwatch**: Millisecond accuracy with split/lap time tracking
